# 原理与公式说明（PRINCIPLE）

本文档讲清楚工具背后的数学模型:标定的**未知量、方程、求解**,以及**坐标系对齐**的推导。
安装与运行请见 [USAGE.md](USAGE.md)。

> 说明:为保证在任何 Markdown 阅读器里都能正常显示,本文公式一律用**代码块 + 纯文本**书写
> (`√` 表示开方,`·` 表示点积,`×` 表示叉积,`²` 表示平方,`ᵀ` 表示转置,`n̂` 表示单位法向)。

---

## 1. 问题背景

采集设备是「**相机绕中心转、被摄物体不动**」的多相机结构:多台相机装在一个绕**转轴**旋转
的机构上,每台相机沿一个圆轨迹拍摄一圈。

- 每台相机装在一个**电机驱动的径向进给机构**上,可沿机械臂朝转轴内外移动。配置字段
  `CameraDisplacement`(下称 `disp`)就是该机构相对电机零位的**径向位移指令值**。
- 相机的**光心**并不在机械连接件上,而是相对连接件有一个固定的三维偏移——**杠杆臂 L**
  (在相机自身坐标系里,所有同型号相机共用一个 L)。

SfM(Metashape / VGGT 等)从图像解出的相机位姿,处在一个**任意单位、任意朝向、任意原点**
的坐标系里(7 个自由度不确定:3 平移 + 3 旋转 + 1 尺度)。我们的目标:

1. 求出**尺度**,把 SfM 单位换算成真实毫米;
2. 把不同次采集**统一对齐**到同一套物理坐标系,便于比较与训练。

---

## 2. 记号

```
d        : 第 d 次采集（标定时的“天/次”）
i        : 相机编号
k        : 同一相机一圈里的第 k 帧
Q(d,i,k) : SfM 给出的该帧相机朝向（camera → world 的旋转矩阵，3x3）
C(d,i,k) : SfM 给出的该帧相机光心位置（3 维向量）
```

---

## 3. 由 SfM 拟合得到的已知量（每次每相机）

对每台相机的一圈光心做**三维圆拟合**,得到:

```
r_sfm(d,i) : SfM 单位下的圆半径
O(d,i)     : 圆心
n̂          : 转轴方向（各相机法向平均后归一化）
```

对每帧构造世界系下的**径向**、**切向**单位向量:

```
v_k = C_k - O
u_k = normalize( v_k - (v_k · n̂) · n̂ )     # 径向单位向量（垂直于转轴、指向外）
t_k = n̂ × u_k                              # 切向单位向量（轨迹前进方向）
```

把它们旋到**相机自身坐标系**并对所有帧求平均,得到两个方向系数向量:

```
a(d,i) = mean_k ( Q_kᵀ · u_k )
b(d,i) = mean_k ( Q_kᵀ · t_k )
```

另外从设备配置 json 读到:

```
disp(i) : 该相机的 CameraDisplacement（电机径向位移指令值）
```

> **a、b 是干什么的**:把「写在相机自身坐标系里的杠杆臂 L」投影成对半径的径向/切向贡献。
> 关键恒等式:
> ```
> a·L = (Qᵀ u)·L = u·(Q L)   —— 即杠杆臂在世界系里的“径向”分量
> ```
> 沿转轴方向的分量只改变高度、不改变“到轴距离”,所以对半径无贡献,直接略去。

---

## 4. 物理模型（核心方程）

机械连接件到转轴的真实半径:

```
R_conn(i) = r + disp(i)
```

其中 `r` 是**电机 0 位时的基础偏移**(disp=0 时相机并不在轴心上)。

光心相对连接件有杠杆臂 `L = (Lx, Ly, Lz)`,于是**光心到转轴的真实半径**:

```
R_opt(d,i) = √[ ( r + disp(i) + a(d,i)·L )² + ( b(d,i)·L )² ]
```

SfM 半径与真实半径只差一个**每次一个的尺度** `s_d`(单位:SfM 单位 / mm):

```
┌─────────────────────────────────────────────────────────────────┐
│  r_sfm(d,i) = s_d · √[ (r + disp(i) + a(d,i)·L)² + (b(d,i)·L)² ]  │   ← 核心方程
└─────────────────────────────────────────────────────────────────┘
```

> **工程依据**:用 SfM 拟合半径 `r_sfm` 对 `disp` 做回归呈高度线性,验证了
> “disp 与径向半径线性对应”的假设,故可把它当作半径参数纳入模型。

## 5. 两种求解场景

### 5.1 单次自解(仅用一次采集)

未知量共 **5 个**:尺度 `s`、基础偏移 `r`、杠杆臂 `L = (Lx, Ly, Lz)`。
每台在位相机给一条方程,共 `N` 条:

| 相机数 N | 方程数 vs 未知量 | 结论 |
|:---:|:---:|:---|
| 4 | 4 < 5 | 欠定,**无法求解** |
| 5 | 5 = 5 | 刚好可解 |
| 6 | 6 > 5 | 超定(最小二乘) |

即:**单次至少要 5 台相机**才可解,6 台才有冗余更稳。

### 5.2 多次联合标定（本工具的第一步 calibrate_rig）

把 `r, L` 当作**所有次共享**的机械常数,每次只多一个自己的尺度 `s_d`:

```
未知量 = r (1 个) + L (3 个) + 每次的 s_d (D 个) = 4 + D
方程   = Σ_d N_d  （各次在位相机数之和，通常远超定）
```

目标函数(非线性最小二乘,Levenberg–Marquardt):

```
minimize (over r, L, {s_d})   Σ_d Σ_i ( s_d · R_opt(d,i)(r,L) − r_sfm(d,i) )²
```

它的意义:**打破 5.1 里“每次必须 ≥5 台”的限制**。例如 6 次、每次仅 4 台,单看都欠定,
合起来是 24 条方程解 4 + 6 = 10 个未知量,照样超定可解。

> 单次自解就是联合标定在 D = 1 的特例(4 + 1 = 5 个未知量)。

解完后,用各次均值的 `ā_i, b̄_i, disp̄_i` 算出每台相机的机械常数 `R_opt(i)`,
连同 `r, L` 一起写入 `rig_calib.json`。

---

## 6. 复用标定,每次只解尺度（第二步 canonicalize）

`r, L` 是**与 disp、与次数无关**的机械常数,可跨次复用。对任意一次新采集
(相机数任意、可缺相机、**可改过 disp / 俯仰**),用**它自己实测的** `disp(i), a(i), b(i)`
重算每台的 `R_opt(i)`,再对在位相机取中位数解尺度:

```
s = median_i [ r_sfm(i) / R_opt(i) ]
c = 1 / s        （单位：mm / SfM单位，即缩放因子）
```

一致性自检用离散度(越小越好,经验上 < 5% 正常):

```
ρ_i    = r_sfm(i) / R_opt(i)
spread = std_i(ρ_i) / mean_i(ρ_i)
```

> **为什么要“按当次 disp 重算”而不是查固定表**:若某次改过相机径向距离(disp),
> 直接按相机号查标定时的标准半径会系统性算错。用当次实测 disp 代入公式重算 `R_opt`
> 即可正确处理;俯仰变化则通过当次实测的 `a(i), b(i)`(来自朝向 Q)自动吸收。

---

## 7. 对齐到统一 canonical 坐标系

求得尺度后,对该次所有帧施加**同一个相似变换**(整体缩放 + 旋转 + 平移):

```
x'      = c · R · (x − O1)      # 变换后的光心位置
R'_cam  = R · R_cam             # 变换后的相机朝向
```

其中:

- 旋转 `R` 把**转轴 n̂** 对到世界 `+Z`;再绕 `Z` 转一个角,使基准相机(默认 cam01)
  的 angle0 光心朝 `+X`。
- 平移把基准相机的**环心 O1** 移到原点(转轴落在 Z 轴、基准圆面落在 z = 0 的 XOY 面)。
- 缩放 `c = 1/s` 把单位变成真实 mm。默认令编号大的相机(cam06)在上、cam01 在下,
  可用 `--flip-z` 反向。

因为对该次**每一帧用的是同一个 c、R、O1**,这是一个**全局相似变换**:
**相机之间的相对位置、朝向、夹角、形状全部保持不变**,只是整体等比缩放并摆正——
不会改变重建的内部几何,只改绝对尺寸与朝向。

> 严格说这是“相似变换”(含均匀缩放),而非仅含旋转+平移的“刚性变换”;
> 但对“内部相对关系不变”这一点,两者一致。

## 8. 术语小结

| 符号 | 含义 | 性质 |
|:---:|:---|:---|
| `disp` | `CameraDisplacement`,相机径向位移指令(相对电机零位) | 每次每相机已知(读配置) |
| `r` | 电机 0 位时连接件到轴的基础偏移 | 机械常数(标定) |
| `L` | 连接件→光心的杠杆臂(相机自身坐标系) | 机械常数(标定) |
| `a, b` | 杠杆臂在径向/切向的投影系数 | 每次每相机已知(拟合朝向) |
| `r_sfm` | SfM 单位下的圆半径 | 每次每相机已知(圆拟合) |
| `R_opt` | 光心到转轴的真实半径(mm) | 由核心方程算出 |
| `s` | SfM 单位 / mm 的尺度;`c = 1/s` 为缩放因子 | 每次一个(求解) |
